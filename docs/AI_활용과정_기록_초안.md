## 1. 주요 활용 AI 도구

| 도구 | 역할 |
| --- | --- |
| Claude (Anthropic) | 매크로 분석 프레임워크 정리, 루틴 설계 피드백, 대시보드 코드 작성(바이브코딩) |

## 2. 진행 과정과 핵심 프롬프트

### 단계 1. 문제 정의: 애널리스트는 매일 무엇을 보는가
- 프롬프트: "증권사 매크로 애널리스트가 데일리 시황 점검할 때 어떤 루틴으로 하는지 알아? 매크로 분석이라고 하면 보통 어떤걸 많이 봐?"
- 결과: 시간대별 루틴, 성장·물가·정책·금융여건 4축 지표 정리
- 추가 질문: "그래서 어떤 결론을 내야돼?" → 결론 4단계(What / So what / View / Implication·Next) 도출

### 단계 2. 내가 만든 루틴 검토
- 프롬프트: "내가 기존에 보내준 루틴은 어때? 네가 평가하기에? 적합해?"
- AI 피드백: 시장 가격(결과) 위주이고 경제지표 서프라이즈(원인)가 약함, 물가·신용 지표 누락, 결론을 AI에 맡기는 구조의 문제, 항목 과다로 지속 가능성 우려
- **내가 수정한 점**: 결론 순서를 "데이터 → AI → 리포트"에서 "데이터 → **내 결론 먼저** → AI → 리포트 비교"로 변경

### 단계 3. 분석 방법 구체화
- 프롬프트: "어떤 걸 확인하고 어떤 걸 분석해서 어떤 결론을 도출할지 … 엄청 세세하게 적어줘. 어떤 걸 보고, 뭘 의미하고, 어떻게 해석하는지."
- 결과: 항목별 "확인할 것 → 의미 → 해석 방법" 가이드 (커브 4패턴, 실질금리·BEI 분해, 주식×금리 조합, 한국 전이 경로, 국면 4분면)
- 추가 요청: "그렇게 나눠서 다시 설명추가해줘" → 매일 / 이벤트일 / 주 1~2회 점검 주기 분리
- **내가 판단한 점**: 매일 10~15분 안에 끝나도록 항목을 주기별로 재배치, 국내 확인처(네이버 증권, 한경컨센서스) 추가

### 단계 4. 바이브코딩으로 대시보드 구현
- 프롬프트: "저 데일리 루틴대로 할 수 있게 대시보드를 만들고 싶어. 금융권 공고보드처럼! 그리고 매일 수행한거 스프레드 시트로 넘어가서 기록까지 되도록."
- 선택한 설계: Vercel 배포, 구글 스프레드시트 기록, 가능한 지표 자동 수집, 혼자 사용
- 구현 내용: 가이드의 해석 규칙을 코드로 옮긴 자동 해석(signals.js), 무료 API 자동 수집, Gemini 종합분석, Apps Script 시트 저장

## 3. AI 결과물 검토·수정 내용 (작성 예시 — 실제 경험으로 채우기)

| AI가 제안한 것 | 검토 결과 | 내가 바꾼 것 |
| --- | --- | --- |
| 실무 루틴에 "모닝미팅·운용역 보고" 포함 | 학생 개인 학습 목적과 맞지 않음 | 보고 단계를 빼고 "내 결론 → 리포트 비교"로 대체 |
| 매일 모든 지표 점검 | 지속하기 어려움 | 매일 / 이벤트일 / 주간으로 분리 |
| 결론을 AI가 생성 | 판단 훈련이 안 됨 | 내 결론을 먼저 쓰고, AI는 피드백 역할 |
| (예) 자동 해석 기준치 | VIX 20, 하이일드 4% 등은 경험적 참고치 | 화면에 "참고치"로 표시 |

## 4. 대시보드 안의 AI 프롬프트 설계 (api/analyze.js)
- 역할: "한국 증권사 리서치센터의 시니어 매크로 애널리스트"
- 분석 원칙 8개를 명시 (점검 순서, 서프라이즈 중시, 성장·물가·정책 분류, 커브·분해 해석, 한국 전이, **데이터에 없는 사실을 지어내지 않기**, 투자 권유 금지)
- 출력 형식 고정: 동인 / 해석 / 한국 전이 / 국면 신호와 뷰 / 다음 체크포인트 / **내 결론에 대한 피드백**
- 개선 기록: (사용하면서 AI 답변이 부정확했던 사례와 프롬프트 수정 내용을 날짜별로 추가)
