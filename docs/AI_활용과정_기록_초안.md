## 2. 진행 과정과 핵심 프롬프트

### 단계 1. 문제 정의: 애널리스트는 매일 무엇을 보는가
- 프롬프트: "증권사 매크로 애널리스트가 데일리 시황 점검할 때 어떤 루틴으로 하는지 알아? 매크로 분석이라고 하면 보통 어떤걸 많이 봐?"
- 결과: 시간대별 루틴, 성장·물가·정책·금융여건 4축 지표 정리
- 추가 질문: "그래서 어떤 결론을 내야돼?" → 결론 4단계(What / So what / View / Implication·Next) 도출

### 단계 2. 내가 만든 루틴 검토
- 프롬프트: "내가 기존에 보내준 루틴은 어때? 네가 평가하기에? 적합해?"
- AI 피드백: 시장 가격(결과) 위주이고 경제지표 서프라이즈(원인)가 약함, 물가·신용 지표 누락, 결론을 AI에 맡기는 구조의 문제, 항목 과다로 지속 가능성 우려
- **내가 수정한 점**: 결론 순서를 "데이터 → AI → 리포트"에서 "데이터 → **내 결론 먼저** → AI → 리포트 비교"로 변경

### 단계 3. 분석 방법 구체화
- 프롬프트: "어떤 걸 확인하고 어떤 걸 분석해서 어떤 결론을 도출할지 … 엄청 세세하게 적어줘. 어떤 걸 보고, 뭘 의미하고, 어떻게 해석하는지."
- 결과: 항목별 "확인할 것 → 의미 → 해석 방법" 가이드 (커브 4패턴, 실질금리·BEI 분해, 주식×금리 조합, 한국 전이 경로, 국면 4분면)
- 추가 요청: "그렇게 나눠서 다시 설명추가해줘" → 매일 / 이벤트일 / 주 1~2회 점검 주기 분리
- **내가 판단한 점**: 매일 10~15분 안에 끝나도록 항목을 주기별로 재배치, 국내 확인처(네이버 증권, 한경컨센서스) 추가

### 단계 4. 바이브코딩으로 대시보드 구현
- 프롬프트: "저 데일리 루틴대로 할 수 있게 대시보드를 만들고 싶어. 금융권 공고보드처럼! 그리고 매일 수행한거 스프레드 시트로 넘어가서 기록까지 되도록."
- 선택한 설계: Vercel 배포, 구글 스프레드시트 기록, 가능한 지표 자동 수집, 혼자 사용
- 구현 내용: 가이드의 해석 규칙을 코드로 옮긴 자동 해석(signals.js), 무료 API 자동 수집, Gemini 종합분석, Apps Script 시트 저장

## 3. AI 결과물 검토·수정 내용 (작성 예시 — 실제 경험으로 채우기)

| AI가 제안한 것 | 검토 결과 | 내가 바꾼 것 |
| --- | --- | --- |
| 실무 루틴에 "모닝미팅·운용역 보고" 포함 | 학생 개인 학습 목적과 맞지 않음 | 보고 단계를 빼고 "내 결론 → 리포트 비교"로 대체 |
| 매일 모든 지표 점검 | 지속하기 어려움 | 매일 / 이벤트일 / 주간으로 분리 |
| 결론을 AI가 생성 | 판단 훈련이 안 됨 | 내 결론을 먼저 쓰고, AI는 피드백 역할 |
| (예) 자동 해석 기준치 | VIX 20, 하이일드 4% 등은 경험적 참고치 | 화면에 "참고치"로 표시 |

- 역할: "한국 증권사 리서치센터의 시니어 매크로 애널리스트"
- 분석 원칙 8개를 명시 (점검 순서, 서프라이즈 중시, 성장·물가·정책 분류, 커브·분해 해석, 한국 전이, **데이터에 없는 사실을 지어내지 않기**, 투자 권유 금지)

## 5. 실제 사용 중 발견한 AI 오류와 개선 (2026-11-11 ~ 11-13)

> 매일 루틴을 돌리면서 교차검증으로 AI 결과물의 문제를 찾고, 원인을 분석해 프롬프트와 코드를 고친 기록입니다. GitHub 커밋 기록에 날짜별로 남아 있습니다.

### 사례 1. AI가 오래된 한국 데이터로 한국장을 반대로 판단 (11/11)
- **발견**: 데이터 대조에서 AI 문장 "KOSPI −0.81%"가 실제(+2.6%)와 불일치. 4개 증권사 리포트 대조 결과도 '불일치' — AI는 "원화 강세 → 반도체 불리, KOSPI 하락"으로 봤지만 실제로는 반도체 주도 +2.6% 반등.
- **원인 분석**: ① 아침 7시 수집 때 KOSPI가 11/9 종가까지만 들어와 있었음(데이터 지연). ② 대조는 '저녁의 최신 데이터'와 비교해 시간 차이까지 오류로 셈. ③ AI 입력에 뉴스가 없어 환율·금리 규칙만으로 한국장을 해석(코어위브 실적·반도체 수출 호조를 모름). ④ 아침에는 미국 장의 영향이 아직 서울 장에 반영되기 전인데, 같은 날 숫자끼리 비교한 '한국 전이' 신호를 그대로 사용.
- **수정**
  - AI가 본 숫자를 '데이터 스냅샷'으로 저장 → 대조는 스냅샷 기준, 이후 새 장 값은 '지금' 칸에 따로 표시(시간 차이를 AI 오류로 세지 않음)
  - 프롬프트에 [한국 데이터 시점] 안내 추가: 한국 숫자에 날짜를 붙이고, 데이터가 오래되면 "데이터 확인 필요"로 쓰고 단정하지 않도록 지시
  - 서울 장이 미국 장 뒤에 열린 경우에만 '한국 전이' 신호를 AI에 전달
  - 언론사 RSS 시장 헤드라인 20~25개를 AI 입력에 추가, "헤드라인 제목에 있는 사실만, (헤드라인) 표시" 규칙
- **결과 (11/13 아침)**: "KOSPI가 11/11 종가까지만 들어왔다" 경고가 자동으로 붙었고, AI도 한국장은 "데이터 확인 필요"라고 쓰며 단정하지 않음.

### 사례 2. 증권사 리포트 여러 개 비교 (11/11)
- **문제**: 리포트 대조 칸이 PDF 1개만 받음. 실제로는 여러 증권사 의견을 함께 봐야 교차검증 의미가 큼.
- **수정**: PDF 최대 5개. 합쳐서 크면 리포트별 핵심을 먼저 뽑은 뒤 모아서 비교. 2개 이상이면 '리포트 간 합의·이견' 섹션 추가.
- **사람의 판단**: 비교에 적합한 리포트는 '장 시작 전 모닝 데일리'이고, 장 마감 시황은 결과를 알고 쓴 리포트라 '결과 확인용'으로 구분해야 공정하다고 정리.

### 사례 3. 데이터 대조의 오탐 (11/13)
- **발견**: AI 문장 "미국 10년물 금리 5% 상향 돌파"를 '금리 = 5%'로 읽어 실제 5.10%와 불일치로 판정.
- **수정**: "돌파·상회·하회·대·부근" 같은 기준선 표현은 정확한 값이 아니라 방향·범위로 확인하도록 규칙 수정.

### 사례 4. 이벤트 일정과 결과별 영향 (11/11)
- **문제**: '이벤트일 점검'이 발표 후 기록만 가능하고, 언제 무엇이 발표되는지·결과에 따라 어떻게 움직이는지 미리 볼 수 없음.
- **수정**: 연준·BLS·BEA·한국은행 공식 일정을 한국시간(미국 서머타임 반영)으로 보여주는 '주요 일정' 카드와 결과별 1차 반응(영향 지도) 추가. 일정 날짜는 AI가 아닌 공식 발표처에서 직접 확인.

### 사례 5. 성과를 숫자로 확인 (11/13)
- 기록 탭에 '성과·인사이트' 추가: AI 숫자 정확도, 한국 데이터 지연 감지 일수, 미국 장의 큰 움직임 다음 서울 장 반응(약 6개월 이력), 판단·국면별 AI 적중률.
- 아침 자동 기록에도 데이터 대조 결과를 남겨, 대시보드에서 저장하지 않은 날도 검증 기록이 빠지지 않게 함.
