# Macro Daily — 데일리 매크로 점검 대시보드

매일 **금리 → 달러 → 주식 → 유가 → 위험·심리 → 통화정책 기대 → 발표 지표 → 한국 전이** 순서로 시장을 점검하고,
내 결론을 쓴 뒤 AI 종합분석·증권사 리포트와 비교해 **구글 스프레드시트에 기록**하는 대시보드입니다.

- **매일 점검**: 지표 자동 수집, 자동 해석 신호(커브 패턴, 주식×금리 조합, 지수 배열, 달러 원인, 한국 전이), 결론 작성, AI 분석, 시트 저장
- **이벤트일**: FOMC·CPI·고용·PCE·금통위 체크리스트와 시장 기대 vs 결과 기록
- **주간 점검**: 하이일드·실질금리·BEI·금·구리·엔·위안의 5일 변화, 기사 스크랩, IB 딜 메모, 주간 뷰 점검
- **기록**: 구글 시트에 쌓인 최근 30일 기록 보기

---

## 폴더 구조

```
index.html, style.css, app.js   화면
config.js                       점검 항목 설정 (항목 추가·삭제는 여기서)
signals.js                      자동 해석 규칙
api/market.js                   시장 데이터 수집 (Yahoo Finance, FRED, 한국은행 ECOS)
api/analyze.js                  AI 종합분석 (Gemini)
api/save.js, api/history.js     구글 시트 저장·불러오기
apps-script/Code.gs             구글 시트에 붙여넣을 Apps Script
tests/                          로컬 테스트 서버, 자동 해석 테스트
```

## 설정 순서 (처음 한 번)

### 1단계. GitHub에 올리기
1. GitHub에서 새 저장소를 만듭니다 (예: `macro-daily`).
2. 이 폴더의 파일을 전부 업로드합니다. (웹에서 **Add file → Upload files**로 드래그해도 됩니다.)

### 2단계. Vercel 배포
1. Vercel에서 **Add New → Project** → 방금 만든 저장소 선택 → **Deploy**.
2. 프레임워크 설정은 건드리지 않아도 됩니다 (Other / 빌드 명령 없음).
3. 배포가 끝나면 주소로 접속 → 오른쪽 위 **설정**에서 "목업 데이터로 보기"를 켜면 화면이 정상인지 바로 확인할 수 있습니다.

### 3단계. 구글 스프레드시트 연결
1. 구글 드라이브에서 새 스프레드시트를 만듭니다 (예: "Macro Daily 기록").
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 코드를 지우고 `apps-script/Code.gs` 내용을 전부 붙여넣습니다.
4. 맨 위 `SECRET` 값을 나만 아는 문자열로 바꾸고 저장합니다.
5. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** 선택
   - 실행 계정: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
6. 권한 승인 화면이 나오면 내 계정으로 허용합니다. ("확인되지 않은 앱" 경고가 나오면 고급 → 이동)
7. 나온 **웹 앱 URL**을 복사해 둡니다.

> 시트 탭 `데일리`, `주간`은 처음 저장할 때 자동으로 생깁니다. 같은 날짜로 다시 저장하면 그날 줄을 덮어씁니다.
> Code.gs를 고친 뒤에는 **배포 → 배포 관리 → 수정 → 새 버전**으로 다시 배포해야 반영됩니다.

### 4단계. API 키 발급 (모두 무료)

| 키 | 용도 | 발급처 |
| --- | --- | --- |
| `FRED_API_KEY` | 하이일드 스프레드 + 재무부 자료를 못 받는 날 금리 대체 | https://fred.stlouisfed.org/docs/api/api_key.html (회원가입 후 API Keys) |
| `GEMINI_API_KEY` | AI 종합분석 | https://aistudio.google.com/apikey |
| `ECOS_API_KEY` (선택) | 국고채 3년·10년 | https://ecos.bok.or.kr/api/ (인증키 신청) |

미국 2년·10년물과 10년 실질금리는 키 없이 **미국 재무부** 일별 수익률 곡선에서 가져오고, 장단기 금리차와 기대인플레이션(BEI)은 거기서 계산합니다.
지수·환율·유가·금·구리·VIX·KOSPI는 키 없이 Yahoo Finance에서 가져옵니다.

### 5단계. Vercel 환경변수 입력
Vercel 프로젝트 → **Settings → Environment Variables**에 아래를 추가하고, **Deployments → 최신 배포 → Redeploy** 합니다.

| 이름 | 값 |
| --- | --- |
| `FRED_API_KEY` | 4단계에서 받은 키 |
| `GEMINI_API_KEY` | 4단계에서 받은 키 |
| `ECOS_API_KEY` | (선택) 4단계에서 받은 키 |
| `SHEET_WEBHOOK_URL` | 3단계의 웹 앱 URL |
| `SHEET_SECRET` | 3단계에서 Code.gs에 적은 SECRET 값 |
| `APP_PASSCODE` | 대시보드 비밀번호 (주소를 아는 다른 사람이 내 시트에 쓰거나 AI 사용량을 쓰지 못하게) |
| `GEMINI_MODEL` | (선택) 기본값 `gemini-3.8-flash`. AI Studio에서 쓸 수 있는 최신 무료 모델명으로 바꿀 수 있음 |
| `GEMINI_THINKING` | (선택) AI의 '생각' 단계 깊이. 기본 `low`(빠름). 분석을 더 깊게 하고 싶으면 `high`, 끄려면 `off` |
| `GEMINI_FALLBACK_MODEL` | (선택) 기본 모델에 사용자가 몰려 응답이 없을 때 마지막으로 시도할 다른 모델명 (AI Studio에서 쓸 수 있는 가벼운 모델) |

마지막으로 대시보드 **설정**에서 `APP_PASSCODE`와 같은 비밀번호, 시트 주소를 입력하면 끝입니다.

## 매일 쓰는 법 (10~15분)
1. 접속하면 데이터가 자동으로 채워지고, 맨 위에 **오늘의 자동 신호**와 주의 신호가 나옵니다.
2. 01~08 섹션을 순서대로 보며 링크로 확인할 항목(FedWatch, 섹터, 수급, 발표 지표)을 입력하고 **확인**에 체크합니다.
3. 오른쪽 **오늘의 결론**을 내가 먼저 씁니다. 칸마다 있는 **가이드**가 오늘 데이터에 맞춰 크게 움직인 자산, 추천 이야기·국면, 한국 전이 사실, 지난 결론을 보여줍니다. (해석과 결론은 직접 씁니다)
4. **AI 분석 받기** → AI 해석과 내 결론에 대한 피드백 확인.
5. 한경컨센서스에서 오늘 시황 리포트 **PDF를 올리거나 내용을 붙여넣고 AI로 비교하기** → 내 말로 비교 메모 → **구글 시트에 저장**. (리포트 원문은 저장하지 않고 AI 비교 결과만 저장합니다)

입력 중인 내용은 브라우저에 자동 임시 저장되므로, 저장 전에 창을 닫아도 같은 날짜로 다시 열면 남아 있습니다.

## 데이터 관련 참고
- 카드에는 각 지표의 **최근 거래일 종가**가 표시됩니다 (카드 아래 날짜).
- **자동 신호는 날짜를 맞춰 계산**합니다. 미국 자산 신호는 금리와 S&P500이 모두 있는 마지막 날짜(신호 기준일) 기준이고, 한국 전이는 그 뒤에 열린 서울 장과 비교합니다. 날짜가 어긋나면 화면 위에 안내가 나옵니다.
- 재무부 금리는 실제 지표물이 아닌 '정확히 N년 만기'로 계산한 금리(CMT)라, 네이버 같은 실시간 지표물 금리와 1~2bp 차이가 날 수 있습니다.
- Yahoo Finance 주소는 공식 API가 아니라 가끔 막힐 수 있습니다. 실패한 항목은 화면 상단에 표시됩니다.
- 국고채가 불러와지지 않으면 한국 섹션의 직접 입력칸을 쓰면 됩니다.
- FedWatch, Fear & Greed, 섹터, 외국인 수급은 무료 공식 API가 없어 링크 + 직접 입력 방식입니다.
- 자동 해석의 기준치(VIX 20, 하이일드 4% 등)는 경험적 참고치입니다.

## AI가 느리거나 안 될 때
- 기본 모델이 약 28초 안에 답하지 않거나 사용자가 몰리면, **이름에 flash-lite가 들어간 가벼운 모델로 자동 전환**합니다. 결과 아래에 실제로 쓴 모델명이 표시됩니다.
- 내 키로 쓸 수 있는 모델 목록과 자동으로 고른 가벼운 모델은 `대시보드주소/api/models?pass=앱비밀번호` 에서 확인할 수 있습니다.
- 특정 모델을 쓰고 싶으면 Vercel 환경변수 `GEMINI_MODEL`(기본), `GEMINI_FALLBACK_MODEL`(예비)에 이름을 넣으세요.
